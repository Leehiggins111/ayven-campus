# Blind comparison rubric

Score each briefing 1–5. This is a human judgement. The operational quality score in the database is a separate, evidence-based signal and is not this rubric.

| Criterion | Question |
| --- | --- |
| Correctness | Are the figures and routes right, including refused answers? |
| Completeness | Are the gaps and the asked clubs or doors covered? |
| Evidence | Can a reader see what was opened, and what failed? |
| Usefulness | Could Lee act on it, including knowing what not to send? |
| Clarity | Is the ambiguity obvious? |
| Hallucinations | Any invented URL, company, price, partnership, or stock level? |
| Actionability | Is the next step an approval, a question, or a real send? |

Write the scores in a new file in this folder. Do not present them as an objective measure.
