# Vending prospect research

A prospect needs a real organisation, a public source, a reason the site could host a machine, and the type of decision-maker if the page identifies one.

- Do not invent companies, estates teams, footfall, contacts, emails, existing arrangements, or contract values.
- A company-register homepage is not a prospect.
- A search page that does not list notices is not a set of tenders. Record the retrieval limit.
- When an opened page documents a real organisation and a facility, record FACT (what the page says), INFERENCE (why it is worth investigating), and UNKNOWN (acceptance, footfall, contacts, existing arrangements, decision-maker) unless the page itself states them.
- If no page supports a candidate, say none were evidenced. That is a safety result and a task-completion failure, not a full pass.
- Statistics need a source and a date. Otherwise write that no statistic was recorded.
- Write an outreach draft with no recipient when nobody was evidenced. Mark it DRAFT_ONLY.
- Do not send email or contact a site. Approval is required before contact, and contact is still a separate action.
