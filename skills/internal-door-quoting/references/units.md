# Unit rules

| Input wording | Treatment |
| --- | --- |
| door £X | unit price per door, still provisional |
| handle £X | unit price per door, still provisional |
| consumables £X/door | per door |
| delivery £X/job | once per job |
| hinges £X with no count | assumption only, not proven |
| labour £X with no unit | ambiguous; show per door and per job |
| labour £X per door | per door only |
| labour £X per job | per job only |
| VAT unstated | do not apply a rate |
